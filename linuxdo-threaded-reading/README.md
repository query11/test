# Linux DO 楼中楼阅读

一个油猴（Tampermonkey / Violentmonkey）用户脚本，在 [linux.do](https://linux.do) 的话题页把评论按回复关系整理成楼中楼，同时保留论坛原生的点赞、回复等操作。

## 功能

- **楼中楼模式**：回复按讨论关系递进缩进，头像之间画连线，标出“回复 某人”和楼主。
- **引用模式**：按楼层顺序阅读，自动在回复前插入被回复评论的引用。
- 话题顶部有“楼中楼 / 引用”切换按钮，选择会记住；切换时保持当前阅读位置。
- 楼中楼模式下用自己的阅读进度条替换原生时间线，可拖动跳转（手机端同样适配）。
- 记住每个话题看到哪里，标出上次之后的新回复并可定位过去。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 新建脚本，把 `linuxdo-threaded-reading.user.js` 的内容整个粘进去保存。
3. 打开或刷新 linux.do 的任意话题页。

油猴菜单里的“开启 / 关闭评论整理”可以临时恢复论坛原样。
