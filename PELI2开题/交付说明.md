## 一、v2 相对 v1 的三处改动

### 1. 铁死亡从「核心」降为「优先但不排他」

依据师兄的意见：「最后我们不一定落脚到铁死亡」「你可以不把范围框的那么死」。v1 的题目虽然没有「铁死亡」，但正文把范围框死了。v2 的改法：

| 位置 | v1 | v2 |
|---|---|---|
| 第4页（研究现状） | 整页讲铁死亡机制 | 改为「耐药的下游效应通路：候选方向与优先级」，列四类候选通路（铁死亡 / 凋亡与存活信号 / 氧化应激适应 / 代谢重编程与AR旁路），铁死亡标「优先」，其余标「并行排查」「备选」 |
| 假说链第三格 | 「铁死亡敏感性改变」 | 「下游效应通路改变（优先铁死亡）」 |
| 目标二 | 「铁死亡是否参与」 | 「下游效应通路筛查（优先检验铁死亡）」，新增**排查顺序**（① 铁死亡 → ② 其他死亡方式 → ③ 氧化应激 / 代谢）与**结果分支** |
| 预期成果 | 「铁死亡是否参与的明确结论」 | 「PELI2 介导耐药的核心下游表型（铁死亡或其他通路）」 |
| 可行性·风险二 | 「铁死亡救援为阴性 → 如实调整结论」 | 增补「按预设分支转向其他下游通路；**功能层面的 PELI2 结论仍然成立**」 |

答辩时如果被问「如果不是铁死亡怎么办」，第8页右侧的结果分支和第10页的风险二就是直接答案。

### 2. 按师兄的内容结构重排，并补「拟创新点」

采用 01–06 分节编号与页眉定位（`03　研究计划 ／ 目标二`　`08 / 15`），新增**提纲页**，第6页底部新增**拟创新点**条。

### 3. 压缩到 15 页

v1 是 16 页正文 + 2 页备用 = 18 页。v2 合并为 15 页，取消备用页。

## 七、使用提示

- 配色：「设计 → 变体 → 颜色 → 自定义」可整体换色，全篇使用主题色而非硬编码色值。
- 字体：「设计 → 变体 → 字体」，或直接改主题字体方案（中文走「东亚字体」槽位）。
- 页眉的「`05 / 15`」是普通文本框，增删页后需手动改；如果经常改页数，可以换成 PowerPoint 的自动页码域。
- 讲稿在每页「备注」窗格中，建议试读后按个人语速调整。
- 需要备用页（A2 面板 A / I、A4 GO 气泡图）时告诉我，图已切好。
