## 六、使用提示

- 修改配色：在 PowerPoint 中「设计 → 变体 → 颜色 → 自定义」即可整体换色，全篇使用主题色而非硬编码色值。
- 修改字体：「设计 → 变体 → 字体」，或直接改主题字体方案（中文走"东亚字体"槽位）。
- 页面结构已分节（封面 / 研究背景 / 前期线索与基础 / 科学问题与研究内容 / 研究实施 / 文献与结语 / 备用页），在幻灯片浏览视图中可折叠。
- 若需压缩到16页，删除最后两张备用页即可，正文叙事不受影响。
- 讲稿在每页的「备注」窗格中，按10–12分钟撰写，建议试读后再按个人语速调整。
