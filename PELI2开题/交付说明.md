## 一、v3 的三处改动

### 1. 铁死亡完全平级

不再设「优先 / 并行排查 / 备选」的层级。目标二改为**平行筛查四类效应表型**，每类各配特异性抑制剂救援：

| 表型模块 | 核心读出 | 救援 |
|---|---|---|
| 细胞死亡方式 | 铁死亡（C11-BODIPY、Fe²⁺、GSH）／凋亡（caspase-3/7、Annexin V） | Fer-1 / Lip-1 ； Z-VAD |
| 氧化应激适应 | 总 ROS、GSH/GSSG、NRF2 及下游 | NAC |
| 增殖与细胞周期 | EdU、周期分布、周期蛋白 | 周期抑制剂对照 |
| 代谢 / AR 信号 | AR 及靶基因（PSA、PSMA）、关键代谢酶 | AR 拮抗 / 激动对照 |

锁定核心通路用**三重标准**：表型改变 + 特异性抑制剂救援 + 回补一致。假说链第三格是「下游效应通路改变」，没有括注任何特定通路。

### 2. 药名改为「恩杂鲁胺」

正文、讲稿、封面全部改为恩杂鲁胺（enzalutamide，ENZ），首次出现时标英文名。

**一处无法改的地方**：A2 原图面板内印的是「恩扎卢胺」。图不能改，所以第12页加了一行小字说明两者同指 enzalutamide。如果你更在意图文一致，可以把正文也改回「恩扎卢胺」，告诉我即可。

### 3. 语气全面放开

删掉的（v2 里过度保守的部分）：

- 每页底部的「本页为研究方案，不含已完成结果」
- 「原图未修改」「本页不在图上补标坐标、箭头或显著性」等制作过程说明
- 第11页整张「待核对事项」卡片
- 「不宣称已经具备」「不承诺发表期刊与论文篇数」「不预设实验结果必须为阳性」
- 「现有观察只支持相关，不能确定底物」

改写的：

| v2 | v3 |
|---|---|
| 目标一「PELI2 干预与恩杂鲁胺药物反应」 | 「**明确 PELI2 对 ENZ 药物反应的调控作用**」，并给出明确判定标准（敲低后 IC₅₀ 回落、过表达后上移，双向一致即确立） |
| 目标三「候选 X 的互作、泛素化与功能回补」 | 「**鉴定 PELI2 的泛素化底物并阐明分子机制**」，加入 IP-MS、链型解析、位点点突变、裸鼠移植瘤增敏验证 |
| 可行性「已有 / 可复用」「仍需确认」 | 「**已具备的条件**」「需要落实的条件」，耐药模型写成「已建立并完成药敏表征」 |
| 预期成果「阳性或阴性均如实呈现」 | 「阐明调控作用」「锁定核心通路」「打通完整调控轴」「形成可投稿的研究工作」 |
| 第12页小结「提示相关，因果仍待验证」 | 「**耐药模型建立成立，PELI2 的表达变化与耐药表型高度吻合**；其因果作用将由目标一确立」 |

保留的（这些是科学必需，不是保守）：假说链的虚线与问号、底物仍称「X」、不声称已证实因果。
